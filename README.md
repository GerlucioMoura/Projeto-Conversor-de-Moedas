# Projeto Conversor de Moedas

## 📌 Contexto

Este projeto é um **Conversor de Moedas básico**, desenvolvido com **HTML, CSS e JavaScript**, como parte dos meus estudos para me familiarizar com comandos, sintaxe e boas práticas de programação web.  

O objetivo principal é **praticar conceitos fundamentais de desenvolvimento front-end**, criando uma aplicação simples e funcional que permita ao usuário converter valores entre diferentes moedas de forma intuitiva.

## 🎯 Objetivos do Projeto

- 🔹 Aprender e aplicar conceitos de **HTML** para estruturar a página.  
- 🔹 Utilizar **CSS** para estilizar e tornar a interface mais agradável.  
- 🔹 Implementar **JavaScript** para manipular dados e realizar os cálculos de conversão.  
- 🔹 Explorar a interação entre elementos da página e scripts.  
- 🔹 Criar uma base sólida para projetos futuros mais complexos.  

## 🚀 Funcionalidades

- Conversão de valores entre moedas selecionadas.  
- Interface simples e amigável para o usuário.  
- Atualização dinâmica dos resultados sem recarregar a página.  

## 📚 Aprendizados

Este projeto serviu como prática para:  
- Estruturação de páginas web.  
- Estilização com CSS.  
- Manipulação do DOM com JavaScript.  
- Lógica de programação aplicada em cálculos matemáticos.
